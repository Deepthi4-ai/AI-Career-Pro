# AI Career Pro 🚀
**Smart Resume & Skill Gap Analyzer**

AI Career Pro is a web application designed to help job seekers optimize their resumes for target job descriptions. Using Natural Language Processing (NLP) and Cosine Similarity, the application compares uploaded PDF/text resumes against a job description to provide an accurate compatibility match score and highlight missing key skills.

---

## ✨ Key Features
* 📄 **Resume Parsing**: Seamlessly reads and extracts text from resumes.
* 🎯 **Match Score Calculation**: Computes semantic match percentage using TF-IDF Vectorization and Cosine Similarity via Scikit-learn.
* 🔍 **Skill Gap Identification**: Detects missing keywords and required competencies from the target job description.
* ⚡ **Sleek UI**: Modern, responsive interface styled with Tailwind CSS featuring automated local browser launch.

---

## 🛠️ Tech Stack
* **Backend**: Python, Flask
* **Machine Learning / NLP**: Scikit-learn, PyPDF2
* **Frontend**: HTML5, Tailwind CSS, JavaScript
